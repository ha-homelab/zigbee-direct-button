# Governance

`4alvit` maintains this derivative and owns review, merge, releases, dependency updates, private security reports and conduct enforcement. Contributors propose changes through public GitHub issues and pull requests with reproducible synthetic tests. Technical decisions and reconsideration take place in the relevant discussion, using the documented hardware scope, evidence and security impact.

Automation assists review; it does not replace independent review or maintainer accountability. Normal merges require reviewed changes and successful required checks. A merge does not authorize flashing a device, operating household equipment or claiming physical acceptance. The original upstream project and Telink remain separate projects with their own maintainers and rights.

On 2026-10-16 the maintainer confirmed familiarity with secure-design principles and common Python/network vulnerabilities, and no bug, enhancement or vulnerability reports outside GitHub during the preceding twelve months. These are human attestations, not test results. Public issue history must also be checked when refreshing an assessment.

Recognitions such as an OpenSSF badge are linked from README within 48 hours and corrected when their status changes.

## Continuity limitation

There is no backup maintainer or established mechanism that can restore repository, CI and release access within one week if the primary maintainer becomes unavailable. Bots and hypothetical account recovery do not establish continuity or a second human maintainer.
