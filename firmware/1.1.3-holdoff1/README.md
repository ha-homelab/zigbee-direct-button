# Experimental normal-update image

This build targets only the already-converted `TS0041-TB` / `mrpevh8p` Telink battery EndDevice. It is not a stock Tuya conversion image.

Read the [upgrade runbook](../../docs/upgrade.md) and [validation record](../../docs/validation.md) before installation. Hardware commissioning is pending. Use `metadata.json` and `SHA256SUMS` to verify your copy. `index.json` is a local-provider example whose image must remain in the same directory.
